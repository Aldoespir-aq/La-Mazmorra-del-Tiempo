# La Mazmorra del Tiempo

Juego de plataformas 2D colaborativo (estilo Prince of Persia).

Resumen

- Modalidad: Equipos de 2 o 3 estudiantes
- Motor(es): Unity / Godot / Phaser (JS)
- Requisitos mínimos: 3 niveles funcionales, tablero de proyecto activo, historial de colaboración en Git

Objetivo

Diseñar y programar un videojuego de plataformas en 2D donde el jugador deba atravesar plataformas, esquivar trampas y superar obstáculos a lo largo de varios niveles.

Cómo empezar (resumen)

- Unity: abrir la carpeta del proyecto en Unity Editor (versión recomendada: 2020 LTS o superior). Ejecutar la escena principal en Assets/Scenes.
- Godot: abrir el proyecto en Godot (2.x/3.x/4.x según la versión usada). Ejecutar la escena principal.
- Phaser (JS): instalar dependencias con `npm install` y ejecutar con `npm start` (configurar según plantilla elegida).

Estructura recomendada del repo

- /UnityProject/ (si se usa Unity)
- /GodotProject/ (si se usa Godot)
- /phaser/ (si se usa Phaser/JS)
- /docs/
- /design/ (tilemaps, assets, mockups)
- README.md, BRANCHING.md, .gitignore, .github/

Contribuir

1. Crear una rama feature siguiendo BRANCHING.md (p. ej. feature/nivel-1)
2. Hacer commits atómicos y abrir Pull Requests hacia `main` (no hacer commits directos en main)
3. Cada PR debe contener una demo (GIF o captura) y ser revisado por al menos un compañero antes de merge
